# Агенты и скиллы проекта «Мы»

Только текстовые инструкции (Markdown). Ни хуков, ни скриптов, ни изменений настроек доступа здесь нет.
Источники (лицензия MIT, тексты лицензий в `vendor-licenses/`), файлы скопированы без изменений, кроме префикса `ecc-` в имени:
- https://github.com/msitarzewski/agency-agents — 27 агентов (14 добавлены в ноябре 2026: маркетинг, продукт, приватность, документация)
- https://github.com/coreyhaines31/marketingskills (коммит 1f83744) — 16 скиллов маркетинга с префиксом `mkt-` (переименованы папка и поле `name`, только `.md`: без `evals/`)
- https://github.com/affaan-m/ECC — 2 агента и 3 скилла
- https://github.com/pbakaus/impeccable — скилл `impeccable` (Apache 2.0), **только текстовая часть**: SKILL.md с вырезанными подкомандами `live`, `generate`, `hooks`, `doctor`, `init`, `document`, `pin` и 31 справочник (критика, polish, типографика, отступы, тексты, пустые состояния, адаптив, `craft-floor` с запретами). Исполняемый движок, хуки, живой режим и телеметрия не установлены

Перед установкой каждый файл прочитан и проверен на команды загрузки и выполнения, обход правил и чтение секретов: подозрительного нет.

## Скиллы маркетинга (`mkt-*`)
| Задача | Скилл |
| --- | --- |
| Позиционирование, аудитория, голос бренда (база для остальных) | `mkt-product-marketing` |
| Тексты лендинга и экранов / вычитка готовых | `mkt-copywriting` / `mkt-copy-editing` |
| План запуска, бета, анонс, чек-лист сайта | `mkt-launch` |
| SEO-аудит / видимость в ИИ-поиске | `mkt-seo-audit` / `mkt-ai-seo` |
| Страница в магазине приложений | `mkt-aso` |
| Первый запуск и активация пользователя | `mkt-onboarding` |
| Конверсия лендинга и форм | `mkt-cro` |
| Контент-план, соцсети | `mkt-content-strategy`, `mkt-social` |
| «Приведи друга», отзывы | `mkt-referrals` |
| Метрики и события аналитики | `mkt-analytics` |
| Интервью, опросы, голос клиента | `mkt-customer-research` |
| Идеи продвижения, психология решений | `mkt-marketing-ideas`, `mkt-marketing-psychology` |

Ссылки внутри скиллов на соседние называют их без префикса (`see copywriting` = `mkt-copywriting`). Примеры в них про SaaS и англоязычный рынок: VK, Telegram, Дзен и RuStore учитывать отдельно. В `mkt-social` есть рецепты `curl` только для чтения публичных лент (HN, Bluesky, RSS), в `mkt-ai-seo` упомянуты `npx`-проверки сайта: сами по себе ничего не запускают.

Скилл `impeccable`: «покритикуй интерфейс», «отполируй экран», «подтяни типографику / отступы / тексты» (команды critique, polish, typeset, layout, clarify, onboard, harden, adapt).

Скилл `prompt-master` (MIT, https://github.com/nidhinjs/prompt-master, только SKILL.md и references/templates.md): «напиши / улучши промпт для Midjourney, Cursor, ChatGPT, Claude Code…». Срабатывает только на явную просьбу про промпт.

Скиллы `hl-verify` и `hl-debug` (MIT, https://github.com/HugoLopes45/hl-skills, только SKILL.md): `hl-verify` — перед словами «готово» сверяет каждое требование с реальным результатом команд (пройдено / провалено / не проверено); `hl-debug` — сначала быстрый способ воспроизвести ошибку, потом опыты, исправление только через падающий тест.

Рассмотрено и не взято: `senior-engineering-partner` (92 КБ, другой стек, скрипты), `apple-design-skill` (123 страницы текста Apple в репозитории: чужие авторские права), `ux-ui-agent-skills` (npm-пакет, 52 проверки с браузером, пересекается с `impeccable`), остальные скиллы `hl-skills` (дублируют `simplify` и `code-review`).

Скиллы: `ecc-design-system` (аудит токенов цвета и отступов), `ecc-e2e-testing` (устойчивые сквозные тесты на Playwright), `ecc-ai-regression-testing` (против слепых зон, когда один и тот же ИИ пишет и проверяет код).

## Не ставили намеренно
- **claude-mem** (память между сессиями): хуки на каждое действие, фоновая служба, база и облачная синхронизация; пишет в том числе содержимое вывода команд, где могут оказаться ключи. Здесь сессия живёт в одноразовом контейнере, пользы нет, а риск есть.
- **headroom** (сжатие контекста): локальный прокси, через который идёт весь трафик и учётные данные, правит `~/.claude.json`, телеметрия включена по умолчанию. Вне наших полномочий и для этой среды не нужен.
- **task-observer** (one-skill-to-rule-them-all): мета-скилл, который ведёт журнал ваших исправлений; для малого набора скиллов пользы мало, журнал может захватывать финансовые данные.
- Исполняемая часть Impeccable (бинарный движок, живой режим с запуском внешних команд, телеметрия).
- Хуки, команды и установщик ECC: исполняют скрипты и меняют глобальные настройки Claude Code.
- Остальные ~220 агентов: к проекту не относятся, а описания каждого агента занимают место в контексте.
