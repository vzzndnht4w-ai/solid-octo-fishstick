# Агенты и скиллы проекта «Мы»

Только текстовые инструкции (Markdown). Ни хуков, ни скриптов, ни изменений настроек доступа здесь нет.
Источники (лицензия MIT, тексты лицензий в `vendor-licenses/`), файлы скопированы без изменений, кроме префикса `ecc-` в имени:
- https://github.com/msitarzewski/agency-agents — 13 агентов
- https://github.com/affaan-m/ECC — 2 агента и 3 скилла

Перед установкой каждый файл прочитан и проверен на команды загрузки и выполнения, обход правил и чтение секретов: подозрительного нет.

## Когда кого звать
| Задача | Агент |
| --- | --- |
| Новая вёрстка, анимации, адаптив | `Frontend Developer` |
| Маленькая точечная правка без лишних изменений | `Minimal Change Engineer` |
| Ревью изменений перед слиянием | `Code Reviewer`, затем `ecc-code-simplifier` |
| Ошибки, которые молча проглатываются | `ecc-silent-failure-hunter` |
| Внешний вид, сетка, типографика, тёмная тема | `UI Designer`, `UX Architect` |
| Понятность сценариев, «глазами новичка» | `UX Researcher`, `Persona Walkthrough` |
| Доступность (контраст, фокус, экранные дикторы) | `Accessibility Auditor` |
| Проверка «действительно ли работает» со скриншотами | `Evidence Collector`, затем `Reality Checker` |
| Скорость и вес страницы | `Performance Benchmarker` |
| Безопасность (ключи, XSS, шифрование, Supabase) | `AppSec Engineer`, `AI-Generated Code Auditor` |

Скиллы: `ecc-design-system` (аудит токенов цвета и отступов), `ecc-e2e-testing` (устойчивые сквозные тесты на Playwright), `ecc-ai-regression-testing` (против слепых зон, когда один и тот же ИИ пишет и проверяет код).

## Не ставили намеренно
- Хуки, команды и установщик ECC: исполняют скрипты и меняют глобальные настройки Claude Code.
- Остальные ~220 агентов: к проекту не относятся, а описания каждого агента занимают место в контексте.
