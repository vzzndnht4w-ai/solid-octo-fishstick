# Уведомления в «Мы»: настройка по шагам

Всё делается с iPhone, без компьютера. Нужны: приложение «Мы» на экране «Домой» (iOS 16.4 или новее), подключённая синхронизация и ваш бесплатный проект на supabase.com (тот же, что для синхронизации).

Уведомления шлёт ваш собственный проект Supabase. Тексты уведомлений общие («Завтра регулярный платёж»): сумм, категорий и заметок в них нет, потому что они хранятся на сервере открытым текстом.

В приложении всё это же есть на экране «Ещё → Уведомления», там можно скопировать нужный текст одной кнопкой.

## 0. Подготовка
1. Добавьте «Мы» на экран «Домой»: Safari → «Поделиться» → «На экран “Домой”». Дальше открывайте приложение только с иконки.
2. «Ещё → Синхронизация» должна быть подключена (пара создана).

## 1. Ключи уведомлений (в приложении)
«Ещё → Уведомления» → «Создать ключи уведомлений».
- Публичный ключ сохранится на телефоне и будет передаваться в ссылке-приглашении партнёру.
- **Приватный ключ показывается один раз.** Нажмите «Скопировать приватный ключ» и вставьте его куда-нибудь на время (например, в заметку), он понадобится в шаге 4. Потерялся: создайте ключи заново (уведомления придётся включить заново на обоих телефонах).

## 2. Таблицы (SQL)
1. Откройте supabase.com → ваш проект → **SQL Editor** → New query.
2. В приложении раскройте «А. Таблицы (SQL)», нажмите «Скопировать», вставьте в Supabase и нажмите **Run**. Должно появиться «Success».

## 3. Функция we-push
1. Supabase → **Edge Functions** → **Deploy a new function** → **Via Editor**.
2. Имя функции: `we-push` (строго так).
3. Удалите пример кода, вставьте код из приложения («Б. Код функции we-push» → «Скопировать»).
4. Найдите переключатель **Verify JWT** и **выключите** его.
5. Нажмите **Deploy**.

## 4. Секреты
Supabase → **Edge Functions** → **Secrets** → добавьте три секрета:

| Имя | Значение |
| --- | --- |
| `VAPID_PUBLIC_KEY` | публичный ключ (показан в приложении в блоке «В. Секреты») |
| `VAPID_PRIVATE_KEY` | приватный ключ из шага 1 |
| `VAPID_SUBJECT` | `mailto:ваш-адрес@почта.ру` |

## 5. Таймер (напоминания по расписанию)
1. Supabase → **Database** → **Extensions** → включите **pg_cron** и **pg_net**.
2. SQL Editor → New query → вставьте «Г. Таймер раз в минуту (SQL)» из приложения (адрес и ключ вашего проекта уже подставлены) → **Run**.

## 6. Включение на телефоне
В приложении: шаг 3 «Включить уведомления на этом телефоне» → «Разрешить». Затем шаг 4 «Отправить тестовое уведомление». Если оно не пришло за минуту, проверьте Настройки iPhone → Уведомления → Мы.

## 7. Второй телефон
Пришлите партнёру **новую** ссылку-приглашение («Синхронизация → Скопировать ссылку»), в ней уже есть публичный ключ. Если партнёр уже подключён по старой ссылке: «Уведомления → У партнёра уже есть ключи» и вставьте публичный ключ. Серверные шаги 2–5 повторять не нужно. Партнёр делает только шаги 3–4 в приложении (включить и проверить).

## Что присылается
- Партнёр добавил операцию, оставил реакцию или комментарий (скрытые и сюрпризные операции не сообщаются).
- Регулярный платёж: за день до (19:00) и в день платежа (09:00).
- Финансовое свидание: раз в неделю (по умолчанию воскресенье 19:00).
- «Долг висит давно»: раз в неделю в среду, если долг больше 1000 ₽ и ему больше 14 дней.
- Вечернее «запишите траты» (по умолчанию выключено).
- Тихие часы (по умолчанию 22:00–08:00): напоминания переносятся на утро.

Напоминания пересчитываются при открытии приложения и после изменений данных, на 14 дней вперёд. Если не открывать приложение больше двух недель, напоминания закончатся.

## Если не работает
| Сообщение в приложении | Что сделать |
| --- | --- |
| Нет таблиц уведомлений | Выполните SQL из шага 2 |
| Функция we-push не найдена | Шаг 3: имя функции должно быть `we-push` |
| Сервер не принял ключ (401) | Выключите Verify JWT у функции (шаг 3) |
| Ошибка функции (500) | Проверьте три секрета (шаг 4) |
| Пара не найдена на сервере | «Синхронизация → Синхронизировать сейчас» |
| Разрешение не выдано | Настройки iPhone → Уведомления → Мы → «Допуск уведомлений» |
